# Jérémie — fichier d'import

Fichier : **`imports/jeremie.json`** — 42 entrées, dont 2 barres de durée.

Pas de thème, pas de catégorie nouvelle : tout arrive dans la catégorie
**Bible** déjà existante, et se mêle à la frise comme le reste.

## Comment l'importer

Menu ☰ → **Importer** → choisir `jeremie.json` → **Ajouter**.

Le fichier est au format `kronos-v1`. L'application propose « Ajouter » ou
« Remplacer » : il faut **Ajouter**. Un second import n'a aucun effet — les
42 entrées sont alors reconnues comme des doublons (même titre, même année)
et ignorées.

## Ce que chaque fiche contient

```
Le Temple et la ville brûlés : 10 ab                      607 av. n. è.
Nebouzaradân incendie le Temple, le palais et toutes les maisons,
et abat les murailles.
Lieu : Jérusalem
Références : Jr 52:12-14 ; 2R 25:8-10
Date : 607 av. n. è. — 5e mois, 10e jour (ab ≈ juillet-août) — chronologie publiée
```

La dernière ligne dit toujours d'où vient l'année : **chronologie publiée**,
**datée par la Bible** (année de règne donnée par le texte), ou
**non datée** pour les épisodes que le texte ne situe pas.

### Les jours de l'année 607

Cinq fiches de 607 portent un mois, pour qu'elles se suivent dans le bon
ordre sur la frise :

1. **9 tammouz** (≈ juillet) — la brèche dans la muraille ;
2. quelques jours après — Tsidqiya capturé près de Jéricho, aveuglé ;
3. **10 ab** (≈ août) — le Temple et la ville brûlés ;
4. **7e mois, tishri** (≈ octobre) — Guedalia assassiné à Mitspa ;
5. ensuite — la fuite en Égypte, qui ouvre les 70 ans de désolation.

Les mois hébreux ont été convertis en mois grégoriens approchants ; chaque
fiche rappelle le mois hébreu d'origine.

### Les épisodes que le texte ne date pas

Cinq entrées sont marquées **≈** et le disent en toutes lettres : la ceinture
de lin (Jr 13), le potier et la jarre brisée (Jr 18-19), Pashhour et les ceps
(Jr 20), les Rékabites (Jr 35), la lettre aux exilés (Jr 29) et le dernier
message d'Égypte (Jr 44). Elles sont placées dans le règne que le texte
indique, sans prétendre à une année.
